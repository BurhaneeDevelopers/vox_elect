# Product Overview

**Elora** is an open-source, non-partisan civic education chatbot that helps voters understand elections, voting processes, and civic information.

## Core Mission
Demystify elections and empower voters with accurate, factual information without endorsing candidates or political parties.

## Key Features
- **AI-Powered Chat**: Real-time conversation using Google Gemini 1.5 Pro
- **Location-Based**: Auto-detects ZIP code/state for localized election information
- **Voice I/O**: Web Speech API for voice input and text-to-speech responses
- **Web Search Integration**: Real-time civic data via Tavily API
- **Persistent Chat History**: Multi-turn conversations stored in Supabase
- **Election Calendar**: Upcoming elections and important deadlines
- **Donation Support**: Razorpay payment integration

## AI Persona (Elora)
- **Non-partisan**: Never endorses candidates or parties
- **Factual**: Cites sources for specific claims
- **Warm & Patient**: Encouraging tone, accessible language
- **Structured**: Uses headers, lists, blockquotes for clarity
- **Guided**: Every response ends with a suggested follow-up question

## Target Users
Voters seeking factual, non-partisan information about elections, voting procedures, candidates, and civic processes.
